# Nora Rasuli — Portfolio

Source for [nora-rasuli.github.io](https://nora-rasuli.github.io), an evidence-led Next.js and TypeScript portfolio.

```bash
npm install
npm run dev
npm run verify
npm run test:e2e
```

The site is statically exported and deployed through GitHub Pages. Professional work is explained without proprietary code, customer data, or screenshots.
